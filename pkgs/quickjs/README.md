# QuickJS

QuickJS is pinned to Bellard's 2026-06-04 release commit in
`lib/sources.nix`. `nix build .#quickjs` builds these rootfs files:

- `/usr/bin/qjs`: JavaScript interpreter, with the upstream REPL and std/os modules.
- `/usr/bin/qjsc`: JavaScript-to-C compiler; executable output invokes `cc` from PATH.
- `/usr/lib/quickjs/libquickjs.a`: static engine and optional libc module helpers.
- `/usr/include/quickjs/{quickjs.h,quickjs-libc.h}`: embedding headers.
- `/usr/share/doc/quickjs/`: upstream Texinfo documentation.
- `/usr/share/licenses/quickjs/LICENSE`: upstream MIT license.

The package is included in the rootfs. It uses MiniDarwin's stage 3 toolchain
and libSystem, with no host SDK or Nix store paths in target load commands.
Like the rest of the userland, it cannot run in the current rootfs until
dyld and libsystem_m are provided. Their missing imports are declared
explicitly in `quickjs.nix` and checked by rootfs assembly.

`quickjsBuildRoot` builds host tools from the same source pin, runs upstream
tests, and generates the REPL C bytecode. This keeps target executables out
of the build process, including `nix build .#cross.x86_64.quickjs` on arm64.
QuickJS bytecode is version-specific; the generator and engine must stay
on the same revision.

`quickjsTest` links C embedding and generated bytecode probes against the
target archive, and checks architectures, signatures and load commands.
The host build executes equivalent probes plus upstream language, BigInt,
module, worker and std/os tests. Build both target checks with:

```sh
nix build .#quickjsTest .#cross.x86_64.quickjsTest
```

For embedding, include `<quickjs.h>` with
`-I${quickjs}/usr/include/quickjs` and link
`${quickjs}/usr/lib/quickjs/libquickjs.a`. An embedder can create a runtime
and context, set memory/time limits, register installer-specific globals,
and evaluate Distribution scripts without registering the std/os modules.
`qjs` exposes filesystem and process APIs and is not an installer sandbox.
The `installer` package embeds this archive to implement its documented
[Installer JS subset](../installer/README.md#installer-javascript).
`quickjsBuildRoot` also exports `include/quickjs/quickjs.h` and
`lib/libquickjs.a`, used by the host installer build from the same source pin.
